# Правила проекта (Telegram Mini App: кликер + экономика)
- Баланс и любая логика денег ТОЛЬКО на сервере. Фронт лишь показывает данные.
- Любое изменение монет проходит через таблицу ledger.
- Все операции с монетами: SQL-транзакции или Postgres-функции (RPC), атомарно.
- Все эндпоинты кроме /auth требуют JWT.
- Один этап = одна рабочая вещь. Коммит после каждого этапа.
- После этапа: проверить, что может сделать читер, отправляя запросы вручную.
